# Paras LinkedIn Automation

Project Paras workspace for a controlled, review-first job-search and LinkedIn optimization workflow.

## Initial operating mode
- Collect and analyze relevant jobs first.
- Do not auto-submit applications until generated resumes and answers have been reviewed.
- Never invent employers, dates, skills, certifications, metrics, or achievements.
- Keep credentials and API keys out of Git.

Development work is prepared on the `project-paras-setup` branch before merging to `main`.
